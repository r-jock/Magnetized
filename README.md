# The Game About Magnets

_A minimalist top-down game prototype exploring unique magnet mechanics and responsive movement controls._

## 🎮 Overview
This project is a solo-developed Unity game built from the ground up. The core concept revolves around collecting and interacting with objects using a magnetic mechanic, wrapped in simple but satisfying progression systems.
