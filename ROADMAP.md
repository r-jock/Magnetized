# 🧲 The Game About Magnets – Full Project Roadmap

## ✅ Current Progress (May 2025)
**Implemented:**
- Top-down player movement (WASD)
- Coin magnet system
- Coins follow the player after entering MagnetZone
- XP and score system with leveling
- Max level cap implemented

**Tools:** Unity 2D, GitHub, GitHub Desktop  
**Branches:** `dev`, `release`, `feature/*`, `bugfix/*`

---

## 📈 Development Milestones

### 🧱 1. Core Gameplay Completion (v0.3.x)
- [ ] Coin spawner with random spawn rate & location

- [ ] Score popups (+XP, +Score, -Score)

### ⚔️ 2. Enemy & Combat System (v0.4.x)
- [ ] Enemy wave spawner
